# YT AI Filter

유튜브 피드와 쇼츠에서 AI 생성 영상을 숨기거나 흐리게 처리하는 가벼운 크롬/엣지 확장 프로그램입니다.
외부 서버 없이 브라우저 안에서만 동작합니다.

## 판별 방식

| 근거 | 동작 |
|---|---|
| 유튜브 AI 라벨 | 시청 페이지에 "변경되었거나 합성된 콘텐츠" 라벨이 보이면 배너 표시 + 채널 자동 차단(옵션) |
| 채널 차단 목록 | 카드에 마우스를 올리면 나오는 🚫 버튼으로 채널 차단 → 이후 해당 채널 영상 전부 필터 |
| 제목 키워드 | `AI 생성`, `sora`, `suno`, `#aivideo` 등 — 팝업에서 편집 가능 |
| 쇼츠 플레이어 | `/shorts/`에서 차단 채널·AI 라벨·키워드에 걸리면 토스트 표시 후 다음 쇼츠로 자동 넘김 |
| 쇼츠 피드 | 홈/검색/채널의 쇼츠 카드도 일반 영상과 같은 규칙으로 필터. 옵션으로 쇼츠 선반 전체 숨김 가능 |
| 허용 채널 | 자동 차단을 취소한 채널은 허용 목록으로 들어가 키워드 판정에서 제외 |

## 설치 (개발자 모드)

1. 이 리포를 클론하거나 ZIP으로 받기
2. `chrome://extensions` (엣지: `edge://extensions`) 열기
3. 우측 상단 **개발자 모드** 켜기
4. **압축해제된 확장 프로그램을 로드** → 이 폴더 선택

## 한계

- 유튜브 AI 라벨은 **시청 페이지에서만** 보이고, 실사풍 콘텐츠만 대상입니다. 그래서 라벨로 채널을 학습시키고 피드에서는 채널 단위로 거르는 구조입니다.
- 유튜브 DOM이 바뀌면 `src/content.js`의 `CARD_SELECTOR`를 갱신해야 합니다.
- 모바일 유튜브 앱에는 적용되지 않습니다.
- 쇼츠 자동 넘김은 "다음" 버튼 클릭(없으면 ↓ 키 입력)으로 동작합니다. 모바일 웹(m.youtube.com) 쇼츠는 불안정할 수 있습니다.
