# YT AI Filter

유튜브 피드와 쇼츠에서 AI 슬롭(AI Slop) 영상을 숨기거나 흐리게 처리하는 크롬/엣지 확장 프로그램입니다.
외부 서버 없이 브라우저 안에서만 동작하며, 수집하거나 전송하는 데이터가 없습니다.

## 만든 이유

유튜브를 열면 AI로 대량 생산한 영상이 추천 목록을 가득 채웁니다.

- 생성형 AI로 뽑아낸 영상, 노래, 커버
- TTS 음성이 대본을 읽어 주는 짜깁기 영상
- 같은 틀로 찍어 내는 자극적인 국뽕 영상

한두 개라면 넘기면 되지만, 지금은 피드의 상당 부분을 차지해서 보고 싶은 영상을 찾는 일 자체가 피곤해졌습니다. 싫어요나 '관심 없음'을 눌러도 비슷한 영상이 계속 나옵니다. 그 피로도가 극심해서, 직접 걸러내려고 이 확장 프로그램을 만들었습니다.

## 기능

- 홈, 검색, 추천, 채널 화면의 AI 영상을 숨기거나 흐리게 처리
- 유튜브가 붙이는 "변경되었거나 합성된 콘텐츠" 라벨을 감지해 채널을 자동 차단
- 설명란에 AI 음성(TTS) 표기가 있는 영상의 채널을 자동 차단
- 카드의 🚫 버튼으로 채널을 직접 차단
- 채널 이름 패턴 필터 (`*AI*`, `뉴스?` 같은 와일드카드)
- 제목 키워드 필터 (AI, TTS, 국뽕 관련 키워드 기본 제공, 직접 편집 가능)
- 쇼츠 플레이어에서 걸리는 영상은 토스트를 띄우고 다음 쇼츠로 자동 넘김
- 쇼츠 선반과 사이드바 메뉴 전체 숨김 옵션
- 차단/허용 목록 JSON 내보내기와 가져오기

## 판별 방식

| 근거 | 동작 |
|---|---|
| 유튜브 AI 라벨 | 시청 페이지에 "변경되었거나 합성된 콘텐츠" 라벨이 보이면 배너 표시 + 채널 자동 차단(옵션) |
| 설명란 TTS 표기 | 설명란에 TTS, ElevenLabs, 인공지능 음성 등이 있으면 배너 표시 + 채널 자동 차단(옵션) |
| 채널 차단 목록 | 카드에 마우스를 올리면 나오는 🚫 버튼으로 채널 차단 → 이후 해당 채널 영상 전부 필터 |
| 채널 이름 패턴 | 채널 이름이나 핸들(`@...`)이 패턴에 맞으면 필터 — 팝업에서 편집 가능 |
| 제목 키워드 | `AI 생성`, `sora`, `suno`, `#aivideo`, `AI 음성`, `국뽕`, `외국인 반응` 등 — 팝업에서 편집 가능 |
| 쇼츠 플레이어 | `/shorts/`에서 차단 채널·채널 패턴·AI 라벨·키워드에 걸리면 토스트 표시 후 다음 쇼츠로 자동 넘김 |
| 쇼츠 피드 | 홈/검색/채널의 쇼츠 카드도 일반 영상과 같은 규칙으로 필터. 옵션으로 쇼츠 선반 전체 숨김 가능 |
| 허용 채널 | 자동 차단을 취소한 채널은 허용 목록으로 들어가 키워드 판정에서 제외 |

판별은 모두 화면에 보이는 텍스트(제목, 라벨, 설명란, 채널)를 기준으로 합니다. 영상이나 오디오 내용을 분석하지는 않습니다.

## 설치

Chrome 웹 스토어에는 올라가 있지 않아서 개발자 모드로 직접 로드해야 합니다. 크롬, 엣지, 브레이브 등 Chromium 기반 브라우저에서 동작합니다.

### 1. 파일 받기

둘 중 하나를 선택합니다.

**방법 A. ZIP으로 받기 (git이 없어도 됩니다)**

1. 리포 페이지 https://github.com/civilian7/yt-ai-filter 를 엽니다.
2. 초록색 **Code** 버튼 → **Download ZIP**을 클릭합니다.
3. 받은 `yt-ai-filter-main.zip`을 원하는 위치에 압축 해제합니다.
   - 확장 프로그램은 이 폴더를 계속 참조하므로, 지우거나 옮길 일이 없는 위치에 두세요. (예: `C:\Tools\yt-ai-filter`)
   - 압축을 푼 폴더 바로 안에 `manifest.json`이 있어야 합니다. 폴더가 한 겹 더 있으면 안쪽 폴더를 선택해야 합니다.

**방법 B. git으로 클론**

```bash
git clone https://github.com/civilian7/yt-ai-filter.git
```

### 2. 브라우저에 로드

1. 주소창에 아래 주소를 입력해 확장 프로그램 관리 페이지를 엽니다.
   - 크롬: `chrome://extensions`
   - 엣지: `edge://extensions`
   - 브레이브: `brave://extensions`
2. 우측 상단(엣지는 좌측 하단)의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**(엣지는 **압축 풀린 항목 로드**)를 클릭합니다.
4. 1단계에서 준비한 폴더(`manifest.json`이 들어 있는 폴더)를 선택합니다.
5. 목록에 **YT AI Filter**가 나타나면 설치가 끝났습니다.

### 3. 확인

1. 툴바의 퍼즐 아이콘(확장 프로그램) 메뉴에서 **YT AI Filter**의 핀을 눌러 툴바에 고정합니다.
2. 이미 열려 있는 유튜브 탭은 **새로고침(F5)** 해야 적용됩니다.
3. 유튜브 영상 카드에 마우스를 올렸을 때 🚫 버튼이 보이면 정상 동작입니다.
4. 툴바 아이콘을 눌러 팝업이 열리고 "걸러낸 영상 N개"가 보이는지 확인합니다.

### 업데이트

- ZIP으로 받은 경우: 새 ZIP을 같은 폴더에 덮어쓴 뒤, 확장 프로그램 관리 페이지에서 YT AI Filter의 새로고침(↻) 버튼을 누릅니다.
- git으로 받은 경우: 폴더에서 `git pull`을 실행한 뒤 같은 새로고침 버튼을 누릅니다.

### 문제 해결

| 증상 | 해결 |
|---|---|
| "매니페스트 파일이 없거나 읽을 수 없습니다" | 선택한 폴더 안에 `manifest.json`이 없습니다. 압축을 푼 폴더의 안쪽 폴더를 선택하세요. |
| 설치 후에도 영상이 걸러지지 않음 | 유튜브 탭을 새로고침하세요. 팝업 상단의 스위치가 켜져 있는지도 확인하세요. |
| 브라우저를 켤 때마다 "개발자 모드 확장 프로그램 사용 중지" 알림이 뜸 | 개발자 모드로 로드한 확장 프로그램에 뜨는 정상 알림입니다. 닫으면 됩니다. |
| 확장 프로그램이 사라짐 | 로드한 폴더를 지우거나 옮기면 사라집니다. 폴더를 원래 위치에 복구하고 다시 로드하세요. |

## 사용법

### 채널 차단

- 영상 카드에 마우스를 올리면 나오는 🚫 버튼을 누르면 그 채널의 영상이 모두 사라집니다.
- 유튜브 AI 라벨이나 설명란 TTS 표기가 있는 영상을 시청 페이지에서 열면 채널이 자동으로 차단되고 배너가 뜹니다. 잘못 걸렸다면 배너의 **차단 취소**를 누르세요. 해당 채널은 허용 목록으로 들어가 이후 키워드 판정에서 제외됩니다.
- 차단/허용 목록은 팝업에서 ✕로 제거할 수 있습니다.

### 팝업

```
╔════════════════════════════════════╗
║ YT AI Filter                [ ●━ ] ║
║ 걸러낸 영상 128개                  ║
├────────────────────────────────────┤
║ 처리 방식              [숨기기 ▾]  ║
║ AI 라벨 영상의 채널 자동 차단  [✓] ║
║ AI 음성(TTS) 영상의 채널 자동 차단 [✓] ║
║ 카드에 🚫 차단 버튼 표시       [✓] ║
├────────────────────────────────────┤
║ 쇼츠                               ║
║ AI 쇼츠 자동으로 넘기기        [✓] ║
║ 피드에서 쇼츠 전부 숨기기      [ ] ║
├────────────────────────────────────┤
║ 차단 채널 (12)                     ║
║ 허용 채널                          ║
├────────────────────────────────────┤
║ 채널 이름 패턴 (한 줄에 하나)      ║
║ [패턴 저장]                        ║
├────────────────────────────────────┤
║ 제목 키워드 (한 줄에 하나)         ║
║ [키워드 저장]                      ║
├────────────────────────────────────┤
║ [목록 내보내기]  [가져오기]        ║
╚════════════════════════════════════╝
```

| 항목 | 설명 |
|---|---|
| 처리 방식 | 숨기기: 카드를 화면에서 제거 / 흐리게: 카드를 흐리게 만들고 `AI · 사유` 배지 표시 |
| 자동 차단 | 유튜브 AI 라벨, 설명란 TTS 표기가 있는 영상의 채널을 차단 목록에 추가 |
| 쇼츠 자동 넘기기 | 쇼츠 플레이어에서 걸린 영상을 건너뜀 |
| 쇼츠 전부 숨기기 | 피드의 쇼츠 선반과 사이드바 Shorts 메뉴를 숨김 |
| 채널 이름 패턴 | 대소문자를 구분하지 않고, 채널 이름이나 핸들이 패턴에 맞으면 걸러냄 |
| 제목 키워드 | 대소문자를 구분하지 않고, 제목에 포함되면 걸러냄 |

### 채널 이름 패턴

팝업의 **채널 이름 패턴** 칸에 한 줄에 하나씩 입력하고 **패턴 저장**을 누릅니다. 채널 이름과 핸들(`@handle`) 모두에 대해 검사하며 대소문자는 구분하지 않습니다.

| 패턴 | 의미 | 일치 예 |
|---|---|---|
| `AI` | 와일드카드가 없으면 포함 검사 | `AI 뉴스`, `오늘의AI` |
| `AI*` | `*` = 0자 이상의 아무 글자. AI로 시작 | `AI 뉴스` |
| `*TV` | TV로 끝남 | `역사 TV` |
| `뉴스?` | `?` = 정확히 한 글자 | `뉴스A`, `뉴스7` |

와일드카드를 쓰면 이름 **전체**가 패턴에 맞아야 합니다(`*AI*`는 `AI`와 같은 뜻). 허용 채널은 패턴에 맞아도 걸러지지 않습니다.

### 키워드 설정

팝업의 키워드 칸에 한 줄에 하나씩 입력하고 **키워드 저장**을 누릅니다. 기본 제공 키워드는 다음 분야입니다.

- AI 생성물: `AI 생성`, `ai generated`, `sora`, `veo 3`, `midjourney`, `suno`, `#aivideo` 등
- AI 음성/TTS: `text to speech`, `ai voice`, `elevenlabs`, `AI 음성`, `AI 목소리`, `AI 더빙`, `#tts` 등
- 국뽕: `국뽕`, `외국인 반응`, `해외 반응`, `외국인 경악`, `세계가 놀란`, `세계가 인정` 등

"외국인 반응" 같은 표현은 평범한 반응 영상도 걸러낼 수 있습니다. 거슬리면 목록에서 지우세요.

이미 키워드를 저장한 적이 있으면 새 버전의 기본 키워드는 자동으로 추가되지 않습니다. 필요한 키워드를 직접 추가하세요.

### 목록 공유

**목록 내보내기**로 차단 채널, 허용 채널, 채널 이름 패턴, 키워드를 `yt-ai-filter-lists.json`으로 저장하고, 다른 PC의 **가져오기**로 합칠 수 있습니다. 가져오기는 기존 목록을 덮어쓰지 않고 합칩니다.

## 한계

- 유튜브 AI 라벨은 **시청 페이지에서만** 보이고, 실사풍 콘텐츠만 대상입니다. TTS 내레이션 영상에는 보통 붙지 않습니다. 그래서 라벨과 설명란 표기로 채널을 학습시키고, 피드에서는 채널 단위로 거르는 구조입니다.
- 제목에 단서가 없고 한 번도 열어 보지 않은 채널은 거르지 못합니다. 🚫 버튼으로 직접 차단하세요.
- 키워드 매칭은 단순 포함 검사라 오탐이 있을 수 있습니다.
- 유튜브 화면 구조가 바뀌면 `src/content.js`의 `CARD_SELECTOR`를 갱신해야 합니다.
- 모바일 유튜브 앱에는 적용되지 않습니다.
- 쇼츠 자동 넘김은 "다음" 버튼 클릭(없으면 ↓ 키 입력)으로 동작합니다. 모바일 웹(m.youtube.com) 쇼츠는 불안정할 수 있습니다.

## 개인정보

모든 설정과 목록은 브라우저의 `chrome.storage.local`에만 저장됩니다. 외부 서버로 보내는 데이터는 없습니다.

## 구조

```
manifest.json        확장 프로그램 설정
src/defaults.js      기본 설정, 라벨/TTS 판별 패턴
src/content.js       유튜브 페이지에서 동작하는 필터 본체
src/content.css      숨김/흐림/배너/토스트 스타일
popup/               툴바 팝업 (html, css, js)
```
